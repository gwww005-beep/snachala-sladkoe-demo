# Сначала сладкое — демонстрационный прототип

Статическая демонстрационная версия мини-магазина студии подарков Елены Дровосековой для GitHub Pages.

Каталог, фотографии и интерактивные карточки сохранены из исходного прототипа. Кнопки заказа подготавливают текст для Telegram; отправку сообщения пользователь подтверждает самостоятельно.

Цены указаны по исходным публикациям. Актуальные стоимость, наличие и условия получения уточняются у Елены.

Этот репозиторий содержит готовую сборку: `index.html`, `styles.css`, `assets/`, `images/` и `fonts/`. Для локального просмотра можно выполнить `python3 -m http.server 8080` в корне и открыть `http://localhost:8080`.
